# **App Name**: MobileDev Portfolio

## Core Features:

- Project Showcase: Display selected mobile app development projects with descriptions, screenshots, and links to app stores and GitHub repositories.
- About Me Section: Showcase a professional bio, skills (Java, Kotlin, Flutter, etc.), and a downloadable resume for Chandan Gepala.
- Contact Form: Enable visitors to contact Chandan Gepala via a functional form that sends email notifications.
- Code Style Consistency Checker: As a tool, employ generative AI to scan project code samples and provide feedback on coding style consistency. This tool identifies areas of improvement to align with best practices for readability and maintainability.

## Style Guidelines:

- Primary background color: Dark navy blue (#0A192F) to create a professional and modern aesthetic.
- Accent color: Metallic silver (#C0C0C0) to highlight key elements and provide a sharp, clean look.
- Text color: Off-white (#E6F1FF) for high contrast and excellent readability against the dark background.
- Headings: 'Montserrat' (sans-serif) for a modern, bold, and geometric appearance.
- Body text: 'Inter' (sans-serif) for a clean, legible, and contemporary feel.
- Note: currently only Google Fonts are supported.
- Use minimalist icons for skills and technologies, maintaining a clean and modern visual style.
- Implement a minimalist layout with generous spacing and intuitive navigation to ensure a seamless user experience.
- Incorporate subtle hover animations and smooth scrolling effects to enhance the user interface with a premium feel.
